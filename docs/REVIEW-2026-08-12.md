## 1. Critical

1. **JWT signing key is `[]byte(cfg.Server.Host)`** (`site.go:77-80`; default `"0.0.0.0"`; no secret field exists in `config.Config`). HS256 is symmetric and the key is public knowledge — anyone can forge an `admin@localhost` admin token. Roles are taken from token claims (stale until expiry) and revocation is an in-memory map (lost on restart, unbounded). This undermines the *entire* permission model: REST, RPC, WS, and CLI agent auth all trust this key.
2. **Audit log is in-memory only.** `site.go:73` uses `audit.NewInMemoryLog()`; no DB-backed `audit.Log` implementation exists anywhere. TAD §13.1's "transactional audit write" guarantee (audit write failure rolls back the data write) is therefore not real in production — every write's audit record vanishes on restart.

## 2. High

3. **Agent session never carried in production paths.** `api/agent.go:81` and `cli/agent_chat.go:103` call `runtime.Execute` without `safety.WithSession`; `runtime.go:384-391` then creates a fresh session every turn → transcript/`seen`/`TargetCount` reset each turn → the TAD §11.1 discovery/operation split and §12.1 bulk-approval continuity **never work across turns**. `SessionManager` has no eviction/TTL (`session.go:102-108`) → unbounded memory growth.
4. **Plan-mode transcript is malformed for real providers.** `plan.go:50-63` appends the assistant plan without `tool_calls`, then `plan.go:91` appends tool messages with empty `ToolCallID`. OpenAI/Anthropic reject tool messages without a matching `tool_call_id` (HTTP 400) — a real-provider session fails on the first plan turn. Only `MockLLM` tests pass; `synthesizeSummary` silently falls back to `deterministicSummary`.
5. **Phase 9 codegen is not wired.** `ui.Regenerate`/`ui.ContentHash` are referenced only by `ui/ui_test.go` — never from `serve.go`, `site.go`, or `server.go`. `orjanda serve` never regenerates `@orjanda/codegen` output on registry hash change; the committed `orjanda-ui/src/generated/` output is stale or hand-verified at best. TAD §6.3 step 3 is structurally unmet.
6. **App lifecycle hooks are dead code.** `app.Definition` is a plain struct (`app/app.go:9-17`); `site.go:99` and `cli/lifecycle.go:71-91` do `any(def).(app.Installable)`, which can never succeed for a struct value → `orjanda install` always prints *"declares no OnInstall hook"*. TAD §7 lifecycle is unreachable.
7. **Bespoke permission gates bypass `perm.Engine`** (PRD §25.1 violation): `api/rpc/rpc.go:106-113` (`hasAnyRole`; the injected `permEngine` is dead at `:79`) and `workflow/engine.go:202-210` (engine's `permEngine` never referenced; empty `AllowedRoles` = zero checks).
8. **Meta API leaks gated field metadata.** `api/meta.go:94-110`: when the caller lacks write permission (or no fields are allowed), `AllowedFields` returns empty → `len(allowed) > 0` is false → **all** gated fields are returned *including their `permission` role string*. `GetDocMeta` also never gates on read permission.

*Resolved (not a bug):* the middleware's PUT/PATCH→`"write"` mapping is safe — `perm.Engine` normalizes `"update"`→`"write"` (`perm/engine.go:146-147,174`), matching the engine's `CheckAction(...,"write")`.

## 3. Medium / low

9. **Migrator gaps** (`dal/migrator.go`): `Diff` is a hand-rolled table/column **set comparison**, not Atlas diffing (Atlas used only as a model representation). Consequences: `AlterColumns` is never populated → **column type changes are silently ignored**; **no `DropTables` detection** → orphaned tables never flagged and the `bench` fail-fast gate (`cli/serve.go:136` counts only CreateTables+AlterTables) misses them; `--allow-destructive` covers only `DROP COLUMN`. Also goose global-state misuse (`SetDialect`/`SetBaseFS`) races concurrent dialects; `Write` timestamp filenames collide if diffed twice in one second.
10. **`order_by` injection surface** (`api/rest/handlers.go:42` passes raw query → `resolveField` passes unknown names through → dialect quotes the column but appends the second token raw: `sqlite/dialect.go:120-128`, same in postgres). Multi-statement rejection by the drivers limits exploitability, but the direction token is unvalidated and ordering by hidden columns is possible.
11. **Child-table naming is camelCase**, inconsistent with TAD §1.4: main tables use `camelToSnake+"s"` (`registry.go:128`) but child tables use `child.DocType + "s"` → `"LeaveDays"` (`migrator.go:95`, `dialect/sqlite/db.go:481`).
12. **Bootstrap** (`orjanda-core/bootstrap.go:147`): logs the admin password via `slog.Info`; Query-then-Insert is not atomic → concurrent `serve` instances could create duplicate admins; the internal `db.Query` at `:69` runs inside a `tx` using `db` not `tx`.
13. **WS agent handler** (`api/agent.go`): `InsecureSkipVerify: true`, `context.WithoutCancel` (`:47`) so approval `ctx.Done` never fires, goroutine-per-message with no per-connection rate limit, per-turn session leak.
14. **Cache** (`cache/cache.go`): documented FIFO-with-re-append, not a true LRU (TAD §9.1 says LRU); `Set` is O(n) on every update.
15. **Event bus ordering**: handlers run in registration order; the "app-dependency order" claim is wiring responsibility, not enforced by `event.Bus`.

## 4. Confirmed solid

- **`perm.Engine`**: RBAC-first, ABAC rules AND-composed, `update`→`write` normalization — clean and matches TAD §2.4/§2.7.
- **`document.Engine`**: every CRUD path checks perm, dispatches hooks, builds audit entries, and drives workflow transitions; actions are consistent.
- **Registry compile**: snake_case pluralization, child-table assembly, `TableName` derivation.
- **Dialect SQL hygiene**: identifiers quoted with `%q` throughout, all values parameterized (except the order_by direction token); sqlite filter keys sorted for deterministic SQL.
- **Middleware chain order**: CORS → Auth → RateLimit → Permission.
- **`testing/site.go` harness**: `TestSite` embeds the real engines, no permission bypass — well-architected; the deleted HR tests were built on exactly this.
- **`agent/tools/tools.go`**: constant tool count per Document (TAD §10.1), gated fields filtered per identity via `perm.AllowedFields`.
- **Errors package**: six codes with wrapping; config loader via Viper.

## 5. Missing tests / validation gaps

- No test with a real `llm.Provider` or a golden transcript asserting valid `tool_call_id` structure (plan-mode corruption is only visible by reading code).
- No migrator tests against a live DB for type changes, dropped tables, or the destructive gate.

- No meta-API test for the field-filter leak case.
- No eviction/concurrency tests for `SessionManager`; no test that codegen runs at serve time; no test that `OnInstall` is called (can't be — dead path).
- `go build`, `go vet`, `go test` all pass, but on unit coverage only; `.golangci.yml` exists but there's no evidence CI runs it.
